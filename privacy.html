개인정보처리방침

작업 기록은 기본적으로 사용자의 기기에 보관됩니다.

시행일: 2026년 9월 21일
운영자: HANSAE LEE · 문의: mugy2869@gmail.com

DonePair 클라우드는 선택 기능입니다. 로그인하거나 직접 업로드하지 않으면 작업 사진, 메모와 보고서는 서버로 전송되지 않습니다.

1. 처리하는 정보와 목적

기기 내 작업 기록: 선택하거나 촬영한 사진, 작업명·일자, 메모, 업체 정보, 체크 항목과 생성된 PDF·이미지를 앱 전용 저장공간에 보관합니다. 카메라·사진 접근은 사용자가 해당 기능을 선택한 경우에만 사용합니다.

선택형 클라우드 계정: Google·네이버·카카오 로그인을 사용합니다. 선택한 로그인 제공자로부터 서비스 이용자 식별자와, 사용자가 제공에 동의한 경우 이메일 주소·표시 이름을 받아 계정 인증과 서비스 제공에 사용합니다. DonePair는 해당 계정의 비밀번호를 받거나 저장하지 않습니다. 로그인 상태 유지를 위한 세션 정보와 사용자가 설정한 업체명을 함께 처리합니다.

사용자가 업로드한 보고서: 작업명·일자·메모, PDF와 미리보기 이미지를 보관·검색하고 고객 공유 링크를 제공하기 위해 처리합니다. 보고서 안에 사용자가 입력한 연락처나 고객 정보가 포함될 수 있으므로 필요한 정보만 입력해 주세요.

공유 및 구독 정보: 공유 링크의 만료·해제 시점과 열람 횟수, 요금제·결제처·구독 상태·거래 식별자를 권한 확인과 부정 사용 방지에 사용합니다. 카드번호 전체는 DonePair 서버에 저장하지 않습니다.

2. 광고

무료 앱은 Google AdMob의 배너 광고와 선택형 보상 광고를 사용할 수 있습니다. 광고 SDK는 IP 주소를 통한 대략적 위치, 기기·앱 식별자, 광고 상호작용, 진단·성능 정보를 광고 제공, 측정과 부정 사용 방지 목적으로 처리할 수 있습니다. 작업 사진과 메모는 광고 사업자에게 보내지 않습니다. 자세한 내용은 Google 개인정보처리방침과 파트너 앱 정보 사용 안내를 확인해 주세요.

3. 보관 기간과 삭제

기기 내 기록은 사용자가 작업 또는 앱을 삭제할 때까지 보관됩니다. 외부 앱으로 공유하거나 백업한 사본은 해당 위치에서 직접 관리해야 합니다.

클라우드 계정과 업로드 보고서는 계정 삭제 시 삭제합니다. 앱의 DonePair 클라우드 화면에서 ‘클라우드 계정 삭제’를 선택할 수 있습니다. 계정 삭제 시 소셜 로그인 연결 정보, 보고서 파일, 고객 링크, 계정과 구독 권한 정보가 삭제되며 기기 안의 보고서는 남습니다. Google·네이버·카카오 계정 자체는 삭제되지 않으며 각 제공자의 계정 설정에서 DonePair 연결을 별도로 해제할 수 있습니다. 법령상 보존 의무가 있는 결제 기록은 정해진 기간 동안 분리 보관할 수 있습니다.

고객 링크는 기본 30일 뒤 만료되며 사용자가 더 일찍 해제할 수 있습니다. 보안 백업에 남은 삭제 데이터는 복구 주기에 따라 지연 삭제될 수 있으며 서비스 복구 외 목적으로 사용하지 않습니다.

4. 제3자 제공과 처리 위탁

로그인 과정에서는 사용자가 선택한 Google, 네이버 또는 카카오의 인증 화면과 API를 사용하며 각 제공자의 개인정보처리방침이 적용됩니다. DonePair는 로그인과 계정 연결에 필요한 최소 권한만 요청합니다. 시스템 공유창에서 사용자가 선택한 앱이나 서비스로 보고서를 전송하면 해당 사업자의 정책이 적용됩니다. 구독 결제는 Apple 또는 웹 결제 사업자가 처리하며 DonePair는 서비스 권한 부여에 필요한 결제 상태와 거래 식별자만 받습니다. 클라우드 운영에 사용하는 호스팅·데이터베이스·파일 저장 사업자는 서비스 제공과 보안을 위해 필요한 범위에서 정보를 처리할 수 있습니다. 실제 운영 사업자와 국외 이전 사항은 정식 클라우드 서비스 공개 전에 이 페이지에 추가합니다.

5. 보호 조치와 이용자 권리

전송 구간 암호화, 세션 토큰 보호, 조직별 접근 통제, 만료 가능한 비공개 공유 링크와 접근 제한을 사용합니다. 사용자는 앱에서 작업을 삭제하고, 클라우드 계정 삭제를 요청하며, 보유 정보의 열람·정정·삭제 또는 처리 제한을 문의할 수 있습니다.

6. 고객지원과 웹사이트

이메일로 문의하면 이메일 주소, 문의 내용과 사용자가 첨부한 파일을 답변과 문제 해결에 사용합니다. 고객 정보가 담긴 사진은 가린 뒤 보내 주세요. 공개 안내 사이트는 GitHub Pages에서 호스팅되며 별도 분석 스크립트나 광고 쿠키를 넣지 않습니다.

7. 아동과 변경 사항

DonePair는 사업 현장용 도구이며 만 14세 미만 아동을 대상으로 하지 않습니다. 처리 방식이 바뀌면 이 페이지와 시행일을 업데이트합니다. 개인정보 관련 문의는 mugy2869@gmail.com으로 보내 주세요.
